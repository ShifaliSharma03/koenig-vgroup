Good to Know

A few tips before you begin

Use a dedicated dev store

Don't practice against a live/production Shopify store. Partner development stores are free, disposable, and safe for testing write operations like draft orders and Flow triggers.

Keep API keys out of git

You'll create .env files for your Shopify and Anthropic API keys during labs — we'll cover .gitignore hygiene on Day 1 so secrets never get committed.

Bring a webcam-friendly setup

Sessions are interactive and hands-on — a second monitor (one for the call, one for coding) makes following along significantly easier.

Claude Code requires a paid plan

There's no free tier — Claude Code needs either a Claude Pro/Max subscription or an Anthropic API account with billing enabled. Budget for this before Day 1.

Claude API usage has a cost

Lab exercises are designed to be token-light, but keep an eye on your Anthropic Console usage dashboard, especially during the RAG and multi-agent modules.
