Why this program

Practical, workshop-first, built on the real stack

Every module pairs a short concept briefing with a guided, hands-on build against a live Shopify development store and the Claude API — no toy examples.

🧪

100% Hands-On

Concept blocks stay under ~30% of class time. The rest is guided labs building real, working code.

🟠

Claude-Powered

Built on the Claude API, Tool Use and the Claude Agent SDK (TypeScript) — including Claude Code for vibe coding.

🟢

Real Shopify APIs

Storefront API, Admin API, webhooks, Shopify Flow and Shopify's own MCP servers against a live dev store.

⚛️

Node.js + React

The agent backend is Node.js/TypeScript; the shopper-facing chat experience is a real React widget.

🔌

MCP & UCP Native

Build a custom Model Context Protocol server and prototype against the Universal Commerce Protocol.

🛡️

Production Guardrails

Admin scopes, Shopify Flow governance, order-risk awareness, prompt-injection defenses and observability.
